# PleaseKeepLPM

> ⚠️ Just-for-fun project made for personal use, not carefully tested. Use at your own risk.

iOS turns Low Power Mode off when charging past 80%. This tweak turns it back on, unless you turned it off yourself.

Built for iOS 17 (roothide). Build with [roothide Theos](https://github.com/roothide/theos): `make package FINALPACKAGE=1`.
